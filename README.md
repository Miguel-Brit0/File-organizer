File Organizer Python

Projeto simples em Python que organiza automaticamente arquivos de uma pasta com base na extensão.

Tecnologias
- Python

Funcionalidades
- Organiza imagens
- Organiza documentos
- Organiza vídeos
- Organiza músicas

Como executar

1. Clone o repositório
2. Execute o arquivo:

python organizer.py

3. Digite o caminho da pasta que deseja organizar.
